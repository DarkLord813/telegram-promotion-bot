# Telegram Promotion Bot

A powerful Telegram bot for creating and scheduling promotional messages in channels and groups.

## Features

- 📝 Create promotions with text, images, and inline buttons
- 📢 Automatically detect channels where bot is admin
- ⏰ Schedule messages (once, daily, weekly, monthly)
- 🔄 Repeat messages for specified number of days
- 👥 Track all bot users
- 📊 View detailed statistics
- 🎯 All commands via inline keyboards

## Deployment on Render

### Prerequisites

1. A Telegram Bot Token (from @BotFather)
2. A Render account
3. Your Telegram User ID (get from @userinfobot)

### One-Click Deploy

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy)

### Manual Deployment Steps

1. **Fork this repository**

2. **Create a new Web Service on Render**
   - Connect your GitHub repository
   - Select "Python" as environment

3. **Add Environment Variables**
